# J'y serai — JE-GE 25·26

Générateur de visuels « J'y serai » pour la Journée de l'Étudiant en Génie Électrique (JE-GE 25·26), 29 et 30 octobre 2026, EPAC.

Chaque participant ajoute sa photo et son nom, puis télécharge un visuel carré (publication) ou vertical (statut WhatsApp). Tout se passe dans le navigateur : aucune photo n'est envoyée ni stockée.

Organisé par l'Amicale Innovation en Génie Électrique (IGE).
